2. System Timing
Figure 1 illustrates the timing diagram for the GeoStreamer acquisition system with a SourceLink gun controller. The first SP of the line is preceded by a Set Linename (SL) and Begin Line (BL) data command from Orca to SourceLink. SL defines the linename and logs in SourceLink and BL sets SourceLink into shooting and external mode. The shot cycle is initiated within the Orca INS by a process which continually updates the time at which the next shot will occur, the SHOT-PREDICT time (i.e., the prediction of the next TZERO or Timezero +dither for Inple source). A trigger is issued at -50ms (GunStart) to the SourceLink gun controller which initiates the gun firing sequence. At the end of the firing cycle the SourceLink controller issues the TIMEBREAK which is received by Orca. At the LSP of the line an EL (End of Line) data command is sent by Orca to SourceLink. EL sets SourceLink offline which prevents guns being fired if any further closures are received. The seismic data is recorded continuously at 1000ms samples using 1PPS from the Real Time Navigation Unit PRTNU to synchronize the timing between navigation and recording system.

Description of Navigational and SourceLink
- The final GPS fix of the line is provided by the SL (GPS L1/L2) & EL (Ephemeris) & GL (Doppler Link) Data contained within the GPS to SourceLink & SL, which log the timestamp and GPS to SourceLink. SL uses SourceLink into a data file for further analysis.
- The main cycle is initiated within the Clock (TS) by a command which continuously updates the time at which the shot was fired and output the GPS (L1/L2) & EL (Ephemeris) fix at the precise time of the event (T2) to the telemetry receiver for further analysis.
- A trigger is issued at (Start Count/Start) to the SourceLink gun controller which initiates the gun firing sequence.
- At the end of the firing cycle, the SourceLink controller adapts the TET, ARTM fixer as requested by Clock.
- At the end of the firing cycle, a log of any data commands to send by Clock to SourceLink (EL fix, Synthesizer fix) are included in the telemetry data stream being logged for further analysis.
- Generation of Events for the Time-based Continuous Recording.
- The precise data is recorded continuously at 100ms intervals using 1PPS from the Real Time Navigation Unit (RTM U) to synchronize the timing between navigation and recording systems.
GPS Monitoring
GPS monitoring of timing is accomplished by comparing the ARTM time signal with the pulses of triggers below including 1PPS from the synthesizer 1PPS timing units.
TET, ARTM vs. T2, SL
expected difference = 50 ms
TET, ARTM vs. TET, [E] Trigger
expected difference = 0 ms
1PPS ARTM vs. T2, Source Link
expected difference = 50ms
1PPS ARTM vs. 1PPS Source Time Unit
expected difference < 100us
The total system tolerance should never exceed 500us.
Data file: SourceLink, timestamp_2008, shot 01
Timestamp unit: seconds as difference between two consecutive events in ARTM.
Trigger signal: ARTM to SL (Ephemeris) signal. Minimum difference in ARTM: 100 ms (500us) (Dither) then nominal. Not specific to any GPS numbering.
