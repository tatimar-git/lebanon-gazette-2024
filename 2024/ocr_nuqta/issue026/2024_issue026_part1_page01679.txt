The candidate is considered competent if s/he demonstrates a best practice performance in all the 4 following criteria for the assessment related to the competence unit 3 – Installing accessories.

Criteria for assessment | Qualifier | YES | NO (*)
The candidate should be able to make the location of the accessories

Install accessories to carcass: shelf pins and rods socket using a measuring tape, a square and a pencil. The candidate should be able to fix the shelf to the pins and the rod to the socket using a drill, screws, and screwdriver.
Install accessories to drawers: slides and handles The candidate should be able to make the location of the accessories using a measuring tape, a square and a pencil. The candidate should be able to fix slides and handles to the drawer using a drill, screw, and screwdriver.
Install accessories to doors: hinges and push to open The candidate should be able to make the location of the accessories using a measuring tape, a square and a pencil. The candidate should be able to fix hinges to the doors and carcass and install push to open mechanism using a drill, screws, and screwdriver.
Install other accessories: pull downs and lighting The candidate should be able to make the location of the accessories using a measuring tape, a square and a pencil. The candidate should be able to fix pull down mechanism to the carcass and a hidden LED lighting to a shelf using a drill, screws, and screwdriver
